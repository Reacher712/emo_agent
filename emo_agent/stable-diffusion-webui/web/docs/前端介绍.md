# 前端介绍

## 概述

本项目是一个基于 Web 技术的 AI 创作平台前端应用，集成了多种 AI 功能，包括图片生成、音频克隆、图生视频、数字人生成等。本文档详细介绍了前端的技术架构、页面结构、功能模块等内容。

## 技术栈

### 核心技术
- **HTML5**: 页面结构和语义化标签
- **CSS3**: 样式设计和动画效果
- **JavaScript (ES6+)**: 交互逻辑和 API 调用
- **Fetch API**: HTTP 请求处理
- **WebSocket**: 实时通信（SadTalker）
- **LocalStorage**: 本地数据存储

### 第三方库
- **Crypto-JS**: JWT Token 生成（可灵 API）
- **Gradio Client**: CosyVoice API 调用（可选）

### 2. 文件转 Base64

```javascript
function fileToBase64(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result);
    reader.onerror = reject;
    reader.readAsDataURL(file);
  });
}
```

### 4. JWT Token 生成

```javascript
async function generateKlingJWTToken(accessKey, secretKey) {
  const header = { alg: 'HS256', typ: 'JWT' };
  const payload = {
    iss: accessKey,
    nbf: Math.floor(Date.now() / 1000),
    iat: Math.floor(Date.now() / 1000),
    exp: Math.floor(Date.now() / 1000) + 3600,
    aud: 'kling-api'
  };
  return KJUR.jws.JWS.sign('HS256', header, payload, secretKey);
}
```

## 错误处理

### 统一错误处理

```javascript
try {
  // API 调用
  const result = await callAPI();
  // 处理结果
} catch (error) {
  console.error('操作失败:', error);
  
  // 友好的错误提示
  let errorMessage = '操作失败';
  if (error.message.includes('网络')) {
    errorMessage = '网络连接失败，请检查网络设置';
  } else if (error.message.includes('API Key')) {
    errorMessage = 'API Key 无效，请检查设置';
  } else {
    errorMessage = error.message;
  }
  
  alert(errorMessage);
}
```

## 性能优化

### 1. 图片懒加载

```javascript
// 使用 Intersection Observer 实现懒加载
const imageObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      imageObserver.unobserve(img);
    }
  });
});
```

### 2. 防抖处理

```javascript
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}
```

### 3. 请求缓存

```javascript
// 缓存 API 响应
const apiCache = new Map();

async function cachedFetch(url, options) {
  const cacheKey = `${url}-${JSON.stringify(options)}`;
  if (apiCache.has(cacheKey)) {
    return apiCache.get(cacheKey);
  }
  
  const response = await fetch(url, options);
  const data = await response.json();
  apiCache.set(cacheKey, data);
  return data;
}
```

## 部署说明

### 本地开发

1. 使用 HTTP 服务器运行（不能直接打开 HTML 文件）
2. 推荐使用 Python 的 `http.server`:
```bash
cd web
python -m http.server 8000
```
3. 访问 `http://localhost:8000`

### 生产部署

1. 配置 API 地址
2. 配置 API Keys
3. 使用 Web 服务器（Nginx、Apache 等）
4. 启用 HTTPS（推荐）
