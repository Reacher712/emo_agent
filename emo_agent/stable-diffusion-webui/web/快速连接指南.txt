==========================================
  Stable Diffusion WebUI 快速连接指南
==========================================

【步骤1】在运行 WebUI 的设备上启动 API 模式

方法A：修改启动文件（Windows）
1. 找到 webui-user.bat 文件
2. 打开并找到 COMMANDLINE_ARGS 这一行
3. 修改为：
   set COMMANDLINE_ARGS=--api --listen 0.0.0.0
4. 保存并运行 webui-user.bat

方法B：命令行启动（Linux/Mac）
在终端运行：
python launch.py --api --listen 0.0.0.0

方法C：添加启动参数
在任何启动方式中添加：--api --listen 0.0.0.0


【步骤2】查找 WebUI 设备的 IP 地址

Windows: 运行 ipconfig，查找"IPv4 地址"
Linux/Mac: 运行 ifconfig 或 ip addr


【步骤3】在前端页面配置 API 地址

1. 打开前端页面（index.html）
2. 点击右上角"设置"按钮
3. 输入：http://[IP地址]:7860
   例如：http://192.168.1.100:7860
4. 点击"保存"


【步骤4】测试连接

1. 在浏览器访问：http://[IP地址]:7860/docs
2. 如果看到 API 文档页面，说明连接成功
3. 在前端页面尝试生成一张图片


【常见问题】

❌ 连接被拒绝
   → 检查 WebUI 是否已启动并添加了 --api 参数
   → 检查防火墙是否阻止了 7860 端口

❌ 跨域错误（CORS）
   → 在启动参数中添加：--cors-allow-origins="*"
   → 或安装 CORS 扩展

❌ 404 错误
   → 确认 API 地址格式为 http://IP:7860（不要加 /api）

❌ 请求超时
   → 检查网络连接
   → 确认两台设备在同一局域网


【测试 API 连接】

在浏览器访问以下地址测试：
http://[IP地址]:7860/sdapi/v1/ping

如果返回 pong，说明 API 正常。


【完成！】

配置完成后，就可以在前端页面使用图片生成功能了。
