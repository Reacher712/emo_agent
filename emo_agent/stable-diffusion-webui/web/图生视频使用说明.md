# 图生视频功能使用说明

## 概述

图生视频功能已完全替换为使用 `ttt` 文件夹中的可灵AI后端实现。新的实现使用独立的 Flask 后端服务，提供更稳定和可靠的视频生成功能。

## 文件说明

### 1. 后端服务文件

- **`kling_backend.py`**: 可灵AI后端服务（Flask应用）
  - 提供图片上传接口：`/api/upload-image`
  - 提供视频生成接口：`/api/generate-video`
  - 提供任务状态查询接口：`/api/task-status/<task_id>`
  - 运行在 `http://localhost:5000`

- **`start-kling-backend.bat`**: 后端服务启动脚本
  - 双击运行即可启动后端服务

### 2. 前端文件

- **`image-to-video.html`**: 图生视频页面
  - 已完全重写，整合了 `ttt/index.html` 的功能
  - 保留了导航栏、AI助手侧边栏、设置模态框
  - 使用新的后端API (`http://localhost:5000`)

## 使用步骤

### 步骤 1: 安装 Python 依赖

**方式一：使用安装脚本（推荐）**

1. 双击运行 `安装依赖.bat`
2. 脚本会自动检测并激活虚拟环境（如果存在）
3. 自动安装所有必需的依赖包

**方式二：手动安装**

如果您使用虚拟环境（`.venv` 或 `venv`），请先激活虚拟环境：

```bash
# 激活虚拟环境（根据您的虚拟环境位置选择）
venv\Scripts\activate          # 如果在项目根目录
# 或
.venv\Scripts\activate          # 如果在项目根目录
# 或
..\venv\Scripts\activate        # 如果在 web 目录
```

然后安装依赖：

```bash
pip install flask flask-cors pyjwt requests python-dotenv
```

**注意**：启动脚本会自动检测并激活虚拟环境，无需手动激活。

### 步骤 2: 配置环境变量（可选）

在 `web` 目录下创建 `.env` 文件，配置可灵AI的密钥：

```env
KLING_ACCESS_KEY=你的访问密钥
KLING_SECRET_KEY=你的密钥
```

如果不创建 `.env` 文件，后端会使用代码中的默认密钥（仅用于测试）。

### 步骤 3: 启动服务

**方式一：一键启动（推荐）**

1. 双击运行 `启动所有服务.bat`
2. 会自动启动后端服务（端口 5000）和前端服务（端口 8000）
3. 两个服务窗口会分别打开，保持打开状态即可

**方式二：分别启动**

1. **启动后端服务**：
   - 双击运行 `start-kling-backend.bat`
   - 或者运行命令：
     ```bash
     cd d:\stable-diffusion-webui\web
     python kling_backend.py
     ```
   - 看到以下输出表示启动成功：
     ```
     🚀 启动可灵AI后端服务...
     📡 访问: http://localhost:5000
     ```

2. **启动前端服务**（新开一个命令行窗口）：
   - 双击运行 `start-server.bat`
   - 或者运行命令：
     ```bash
     cd d:\stable-diffusion-webui\web
     python -m http.server 8000
     ```

### 步骤 4: 访问页面

在浏览器中访问：`http://localhost:8000/image-to-video.html`

**重要提示**：
- 后端服务（端口 5000）和前端服务（端口 8000）**必须同时运行**
- 如果只启动前端，图生视频功能将无法使用
- 如果只启动后端，前端页面无法访问

### 步骤 5: 使用图生视频功能

1. 点击"选择图片"按钮，上传一张图片（支持 PNG、JPG 格式，最大 10MB）
2. 在文本框中输入视频描述（例如："宇航员在太空中漂浮，背景是美丽的地球和星空"）
3. 选择视频质量（标准模式或专业模式）和视频时长（5秒或10秒）
4. 点击"开始生成视频"按钮
5. 等待视频生成完成（可以在监控面板查看任务状态）

## 功能特性

### 1. 任务监控面板

- **实时状态**: 显示当前任务、任务状态、运行时间、成功/失败统计
- **任务详情**: 显示任务ID、创建时间、更新时间、视频时长、视频URL
- **任务历史**: 显示所有历史任务记录，包括状态、创建时间、耗时等

### 2. 自动轮询

- 任务提交后，系统会自动轮询任务状态
- 每5秒查询一次任务状态
- 最多查询120次（10分钟）

### 3. 本地存储

- 任务历史保存在浏览器的 `localStorage` 中
- 页面刷新后可以恢复当前任务和历史记录

## 注意事项

1. **后端服务必须运行**: 前端页面需要后端服务 (`http://localhost:5000`) 才能正常工作
2. **API密钥配置**: 如果使用自己的可灵AI密钥，需要在 `.env` 文件中配置，或者修改 `kling_backend.py` 中的默认密钥
3. **CORS问题**: 后端已配置 CORS，允许所有来源的请求。如果遇到 CORS 错误，请检查后端服务是否正常运行
4. **网络连接**: 确保能够访问可灵AI的API服务器 (`https://api-beijing.klingai.com`)

## 故障排查

### 问题1: 后端服务无法启动

**错误：`ModuleNotFoundError: No module named 'flask'`**

- **原因**：未在虚拟环境中安装依赖，或未激活虚拟环境
- **解决方案**：
  1. 运行 `安装依赖.bat` 自动安装依赖
  2. 或手动激活虚拟环境后安装：
     ```bash
     # 激活虚拟环境
     venv\Scripts\activate  # 或 .venv\Scripts\activate
     # 安装依赖
     pip install flask flask-cors pyjwt requests python-dotenv
     ```
  3. 启动脚本会自动检测虚拟环境，如果找不到会使用系统Python

**其他问题**：
- 检查端口 5000 是否被其他程序占用
- 查看控制台错误信息

### 问题2: 前端无法连接到后端

- 确认后端服务正在运行（访问 `http://localhost:5000/api/health` 应该返回 `{"status": "healthy"}`）
- 检查浏览器控制台是否有错误信息
- 确认前端页面通过 `http://localhost:8000` 访问（不是 `file://` 协议）

### 问题3: 视频生成失败

- 检查可灵AI的API密钥是否正确配置
- 查看后端服务的控制台输出，查看详细错误信息
- 检查图片大小是否超过 10MB
- 检查提示词是否为空

### 问题4: 任务状态查询失败

- 确认任务ID是否正确
- 检查网络连接是否正常
- 查看浏览器控制台的错误信息

## 与原实现的区别

1. **独立后端服务**: 不再依赖前端的直接API调用，使用独立的 Flask 后端服务
2. **更好的错误处理**: 后端服务提供更详细的错误信息和状态码
3. **任务监控**: 新增了完整的任务监控面板，可以查看任务状态和历史记录
4. **本地存储**: 任务历史保存在浏览器本地，页面刷新后不会丢失

## 技术栈

- **后端**: Flask, Flask-CORS, PyJWT, Requests
- **前端**: 原生 JavaScript, HTML5, CSS3
- **API**: 可灵AI视频生成API
